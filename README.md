## 🇨🇳 中文

面向医生、研究人员和医学内容团队的领域进展跟踪技能，用于跟踪某主题的研究、预印本、指南与共识、监管、临床试验、会议及专业资讯。发现环节采用多路并行：先同时跑通用检索与学术检索，再并行尝试 PubMed、Europe PMC、Crossref 三个结构化入口补充完整题录与摘要，任一入口失败即跳过，正式研究仍不足时才追加预印本。筛选强调宁缺勿滥，预警或掠夺性期刊、同行评议不透明的低质量论文不进入报告。首次检索生成一份面向医生阅读的飞书进展报告，并邀请用户确认订阅定时监控；确认后创建定时任务，此后每期生成新报告，只呈现新增进展变化。

- 给定一个医学主题 → 并行检索研究、预印本、指南/共识、监管、临床试验、会议与资讯

- 首期生成医生可读的飞书进展报告 → 不暴露检索流水与内部台账
- 邀请确认订阅 → 确认后创建定时任务，定期推送
- 后续每期只强调新增进展变化 → 沿用上一期配置减少重复

## 🇬🇧 English

A field-tracking skill for doctors, researchers and medical content teams, covering studies, preprints, guidelines and consensus, regulation, clinical trials, conferences and professional news. Discovery runs multi-path in parallel: general and scholar search first, then structured lookups against PubMed, Europe PMC and Crossref for complete records and abstracts, skipping any failing entry point rather than retrying, and adding preprint search only when formally published evidence is still thin. Filtering favors omission over noise: predatory or low-quality, non-transparent journals stay out. The first pass produces a physician-facing Feishu progress report and invites the user to subscribe; once confirmed, a scheduled task is created and each new issue shows only what changed.

### ✨ What it does

- Give one medical topic → parallel discovery across studies, preprints, guidelines, regulation, trials, conferences and news
- General plus scholar search, then structured PubMed / Europe PMC / Crossref records
- Predatory and low-quality papers filtered out → only clickable sources with real evidence survive
- First issue delivers a physician-facing Feishu progress report → no search logs or internal ledgers exposed
- Invites subscription confirmation → creates a scheduled monitoring task once approved
- Each later issue highlights only what is new → reuses the prior configuration to avoid repeats
